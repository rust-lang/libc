# Agent instructions

## LLM usage policy

Follow the Rust project's [LLM usage policy]. It applies to all LLM-generated
text even if a human later edits it.

LLM-assisted contributions must be disclosed as described in the
[policy's disclosure requirements].

## pull requests guidance

Pull request must be opened by human. Any automated workflow
including writing description is prohibited.
Follow [CONTRIBUTING.md] and the PR checklist for [libc API changes] or [ctest API changes].
